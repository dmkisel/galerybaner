# Галерея шаблонов

Внутренний сервис для работы с баннерами и текстами коммуникаций: каталог
картинок, конструктор текста на баннере, блокнот текстовых шаблонов, витрина
посадочных мест в приложении и история готовых макетов.

## Быстрый старт

```bash
cp .env.example .env
docker compose up -d --build
```

Интерфейс — <http://localhost:8501>, Postgres снаружи — `localhost:5433`.

## Разделы

- **Галерея шаблонов** — картинки Ordinary и Popup, теги, цвет, избранное.
- **Блокнот** — текстовые шаблоны (Ordinary, Popup, Push, СМС) с фильтрами.
- **Конструктор** — наложение текста на баннер, сравнение масштабов, Popup с подложкой.
- **Витрина** — примерка баннеров на экранах приложения; данные из Airflow или из избранного истории.
- **История** — снимки собранных макетов по каналам, избранное и удаление.
